# ♻️ SampahIn

> **Integrated Waste Management System**
> 
> Aplikasi manajemen sampah terintegrasi berbasis desktop/GUI untuk mempermudah pencatatan, pelacakan, dan pengelolaan data sampah secara efisien dan sistematis.

---

## 💡 Fitur Utama

* **Manajemen Data Sampah:** Pencatatan jenis, berat, dan kategori sampah secara *real-time*.
* **Sistem Akun Pengguna:** Autentikasi aman untuk admin dan pengguna reguler.
* **Pelacakan Distribusi:** Monitoring alur sampah dari pengumpulan hingga pemrosesan akhir.
* **Pelaporan & Analitik:** Pembuatan laporan harian/bulanan secara otomatis.
* **Antarmuka Intuitif:** Desain UI/UX yang minimalis dan mudah digunakan oleh operator.

## 🛠️ Teknologi yang Digunakan

* **Bahasa Pemrograman:** Java (JDK 17+)
* **Database:** MySQL
* **UI Framework:** JavaFX / Java Swing *(Pilih salah satu)*
* **Build Tool:** Maven / Gradle *(Opsional, hapus jika tidak pakai)*

## 📋 Prasyarat Sistem

Sebelum menjalankan aplikasi, pastikan sistem Anda sudah terinstal:

1. **Java Development Kit (JDK)** versi 17 atau lebih baru.
2. **MySQL Server** (seperti XAMPP, WAMP, atau MySQL Workbench).
3. IDE Java (IntelliJ IDEA, Eclipse, atau Apache NetBeans).
